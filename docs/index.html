🧩 Maze Generator & Solver

Generate, animate, and solve mazes — all in your browser

View on GitHub →

✨ Features

🏗️ 3 Generation Algorithms

Recursive Backtracking, Prim's, and Kruskal's — each producing a distinct maze structure.

🔍 3 Solving Algorithms

BFS, A*, and Dijkstra with step-by-step animated visualisation of the search.

📊 Performance Comparison

Compare execution time and path length across all three solvers on the same maze.

🎛️ Configurable Size

Adjust the grid from 5 × 5 to 51 × 51 with a single slider.

🚀 Quick Start

  1. Clone the repo: git clone https://github.com/manne1086/mazesolver.git
  2. Install dependencies: pip install streamlit numpy matplotlib
  3. Run the app: streamlit run app.py
  4. Open http://localhost:8501 in your browser and start exploring!
